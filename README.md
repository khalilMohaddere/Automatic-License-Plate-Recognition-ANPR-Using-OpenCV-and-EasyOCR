# Automatic-License-Plate-Recognition-ANPR-Using-OpenCV-and-EasyOCR
Automatic Number Plate Recognition (ANPR) system using Python and OpenCV. Detects vehicle license plates through image processing and contour detection. Applies Canny Edge Detection and image segmentation to locate license plates. Uses EasyOCR to extract alphanumeric characters from detected plates. Displays recognized license plate numbers with bounding boxes on the original image.
